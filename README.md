# Noïde

Projet de conception d'un petit robot humanoïde pour le faire marcher et reproduire des mouvements humains.


J'ai commencé ce projet en octobre 2025, par un premier prototype qui avait pour but de m'aider plus tard lors de la modélisation 3D (cette étape été importante puisse que je ne suis parti d'aucun modèle existant) (voir dans le dossier photos il y a une photo de ce premier prototype).

En mars 2026, je suis passé sur le deuxième prototype, cette fois je me suis fixé pour objectif de le faire marcher. Pour cela le prototype est constitué de deux jambes et d'un bassin, afin de remplir mon objectif j'ai choisi de mettre uniquement les éléments essentiels à la marche (STM32 (microcontrôleur), capteur d'angle, PCA9685 pour commander mes servomoteurs, module Bluetooth pour communiquer avec une radiocommande que je conçois en parallèle).
